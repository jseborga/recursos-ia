Práctica de Física Básica I

Cada estudiante recibe los mismos seis problemas con datos distintos, generados a partir de su código. Las respuestas se calculan con código, no con un modelo de lenguaje, y se aceptan con una tolerancia del 2 %.

Usa coma o punto decimal. g = 9,81 m/s². Se muestra un ejemplo con el código 1234567.
