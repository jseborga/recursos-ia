Elementos finitos en una dimensión

Una barra (o un potencial) con extremos fijos y una carga. El método de elementos finitos aproxima la solución con rectas por tramos y resuelve un sistema tridiagonal. Cambia el número de elementos y observa cómo baja el error; la pendiente de la recta de convergencia es el orden del método. Corresponde a FIS-243 Cálculo Numérico y Programación y MAT-132 Ecuaciones Diferenciales (plan 2009).

−u″(x) = f(x), u(0) = u(1) = 0 · forma débil: ∫u′v′ dx = ∫f v dx · K = (1/h)·tridiag(−1, 2, −1)
